# Number Guessing Game

A simple console-based **Number Guessing Game** implemented using **Python, Java, C++, and JavaScript**.

The program generates a random number between **1 and 100**, and the player tries to guess the correct number. After each attempt, the game provides hints whether the guessed number is **higher or lower** than the target number. The game continues until the correct number is guessed and displays the total number of attempts.

---

## Features

- Random number generation
- User input handling
- Higher/lower hints after each guess
- Attempt counter
- Success message after correct guess
- Implemented in multiple programming languages
